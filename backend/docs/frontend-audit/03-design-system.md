# 03 — Design System Inventory & Design Tokens

## 1. Color Palette Tokens
* **Base Background**: `#020617` (`bg-slate-950`)
* **Surface Panels**: `#0f172a` (`bg-slate-900/80`) with `border-slate-800`
* **Brand Primary**: Indigo / Violet (`#6366f1` / `#4f46e5`)
* **Success Accent**: Emerald (`#10b981`)
* **Warning Accent**: Amber (`#f59e0b`)
* **Danger Accent**: Rose (`#f43f5e`)

## 2. Typography & Radius Rules
* **Font Family**: Inter, system-ui, sans-serif
* **Monospace**: `font-mono` for IDs, hashes, amounts, timestamps
* **Card Border Radius**: `rounded-xl` (`12px`)
* **Button/Badge Radius**: `rounded-lg` (`8px`)
