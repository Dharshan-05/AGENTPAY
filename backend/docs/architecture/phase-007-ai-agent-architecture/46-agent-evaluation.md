# AGENTPAY — 46: Agent Task Success & Safety Compliance Metrics

## 1. Agent Evaluation Scorecard

$$\text{AgentScore} = (\text{TaskSuccessRate} \times 0.4) + (\text{PolicyComplianceRate} \times 0.4) + (\text{ToolAccuracyRate} \times 0.2)$$

Agents exhibiting Policy Compliance Rates $< 100\%$ are immediately flagged for security quarantine and capability restriction.
