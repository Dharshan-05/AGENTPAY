# AGENTPAY — 33: 6 Autonomy Levels (Level 0 Suggestion to Level 5 Autonomous)

## 1. Autonomy Level Matrix

| Level | Classification | Execution Mode | Security Controls |
| :--- | :--- | :--- | :--- |
| **Level 0** | Suggestion Only | Displays recommendations only | Zero execution authority |
| **Level 1** | Human Confirmed | User confirms every action | 100% human confirmation required |
| **Level 2** | Low-Risk Automated | Search & Cart automated | Payments require human approval |
| **Level 3** | Controlled Autonomy | Auto-approve under ₹2,000 | AGENTGUARD policy check mandatory |
| **Level 4** | High Autonomy | Auto-approve under ₹10,000 | Strict 12-D ML risk scoring |
| **Level 5** | Fully Autonomous | System default: **DISABLED** | Restricted to trusted sandboxes |
