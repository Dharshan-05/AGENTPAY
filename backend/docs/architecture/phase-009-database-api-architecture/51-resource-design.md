# AGENTPAY — 51: RESTful Resource-Oriented Naming & Path Architecture

## 1. Primary RESTful Resource Taxonomy

* `/api/v1/tenants`: Tenant management resources.
* `/api/v1/users`: Human account owner resources.
* `/api/v1/agents`: Autonomous AI agent resources.
* `/api/v1/merchants`: Merchant seller resources.
* `/api/v1/orders`: Commercial purchase order resources.
* `/api/v1/payment-intents`: Proposed payment intent resources.
* `/api/v1/payments`: Settlement payment resources.
* `/api/v1/refunds`: Financial refund resources.
* `/api/v1/approvals`: Approval Center escalation resources.
* `/api/v1/webhooks`: Gateway webhook ingress endpoints.
