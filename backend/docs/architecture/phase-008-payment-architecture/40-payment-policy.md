# AGENTPAY — 40: Multi-Dimensional Payment Policy Cap Configuration

## 1. Configurable Policy Dimensions

* **Single Transaction Limit**: Maximum amount permitted per individual payment (e.g. ₹10,000.00).
* **Daily Budget Cap**: Cumulative 24-hour spending cap per agent (e.g. ₹50,000.00).
* **Category Restrictions**: MCC blacklist (e.g. Gambling, Crypto, Foreign Wire transfers blocked).
* **Auto-Approval Ceiling**: Maximum threshold for autonomous execution without human review (e.g. ₹2,000.00).
