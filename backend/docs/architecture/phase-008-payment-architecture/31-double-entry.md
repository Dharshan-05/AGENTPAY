# AGENTPAY — 31: Double-Entry Accounting Engine ($\sum \text{Debit} = \sum \text{Credit}$)

## 1. Accounting Equation Invariant

Every financial transaction posts balanced debit and credit journal entries:

$$\sum \text{Debits} = \sum \text{Credits}$$

Example: Payment of ₹2,500.00:
* Debit: `User_Wallet_Settlement_Account` ₹2,500.00.
* Credit: `Merchant_Payable_Account` ₹2,500.00.
