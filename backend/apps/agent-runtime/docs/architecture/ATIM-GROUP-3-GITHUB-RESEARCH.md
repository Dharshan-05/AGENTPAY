# AGENTPAY — ATIM Group 3 GitHub Reference Architecture Research

## Overview
This document records the architectural research and pattern evaluation conducted for **ATIM Group 3** against industry-standard open-source agentic and security framework repositories.

---

## Reference Repository Analysis

### 1. OpenAI Agents SDK (`openai/openai-agents-python`)
- **Patterns Studied**: Typed tool definitions, Pydantic structured output models, tracing/observability spans, guardrail hooks, explicit agent execution boundaries.
- **AGENTPAY Requirement**: Structured tool proposal generation without giving LLM direct code execution or financial authorization capability.
- **Decision**: **ADAPT**
- **Rationale**: Adopt Pydantic typed tool proposals and schema contracts. Reject LLM autonomous tool execution. Tool proposals generated by ATIM must pass server-side RBAC, AGENTGUARD, FRAUDGUARD, and HITL before execution.
- **Security Impact**: Positive. Ensures tool execution boundaries remain strictly server-side.
- **Dependency Impact**: Zero added dependencies. Uses standard FastAPI + Pydantic.

### 2. Instructor (`567-labs/instructor`)
- **Patterns Studied**: Structured output validation, Pydantic schema enforcement, validation retries with error feedback loops, malformed LLM response handling.
- **AGENTPAY Requirement**: Reliably parse LLM proposals into `ATIMProposedIntent` and `ATIMPlanProposal` with fail-closed fallback.
- **Decision**: **ADAPT**
- **Rationale**: Adopt native Pydantic schema validation and retry/fallback patterns via `LLMRouter` and `RuleBasedIntentExtractorProvider`.
- **Security Impact**: Positive. Invalid or malformed LLM JSON schema outputs fail closed to rule-based fallback without executing invalid transactions.
- **Dependency Impact**: Zero added dependencies. Implemented natively in Python/Pydantic.

### 3. LiteLLM (`BerriAI/litellm`)
- **Patterns Studied**: Multi-provider LLM routing, automatic provider fallback (OpenAI $\rightarrow$ Anthropic), model timeout management, token cost tracking.
- **AGENTPAY Requirement**: High-availability LLM router for transaction intent extraction with automatic fallback.
- **Decision**: **ADAPT** (Custom Native Implementation)
- **Rationale**: Adopt primary/secondary provider routing and fallback concepts. Reject introducing `litellm` package dependency to keep the core security attack surface minimal.
- **Security Impact**: Positive. Reduces external dependency vulnerabilities.
- **Dependency Impact**: Zero added dependencies. Built natively with OpenAI and Anthropic SDKs.

### 4. Guardrails AI (`guardrails-ai/guardrails`)
- **Patterns Studied**: Input/output validation rails, prompt injection detection validators, PII masking, toxic content filtering.
- **AGENTPAY Requirement**: Real-time prompt injection defense, secret redaction, PII masking, and trust boundary envelopes.
- **Decision**: **ADAPT** (Custom Native Implementation)
- **Rationale**: Adopt validation pipeline concepts. Reject replacing server-side AGENTGUARD or adding `guardrails-ai` dependency. Prompt validation is executed by `ATIMSecurityClassifier` and `ATIMTrustBoundary`, while policy authority remains exclusively with AGENTGUARD.
- **Security Impact**: Positive. Maintains strict server-side policy authority.
- **Dependency Impact**: Zero added dependencies.

### 5. Microsoft AutoGen (`microsoft/autogen`)
- **Patterns Studied**: Multi-agent interaction loops, agent delegation, workflow orchestration.
- **AGENTPAY Requirement**: Deterministic execution of financial transaction plans.
- **Decision**: **REJECT**
- **Rationale**: Reject multi-agent autonomous negotiation or execution loops for financial transactions. Autonomous multi-agent loops introduce non-deterministic policy bypass risks. ATIM uses a single deterministic DAG plan validation engine.
- **Security Impact**: Positive. Eliminates multi-agent delegation feedback loops.
- **Dependency Impact**: Zero added dependencies.
